Будь-яку програму, від калькулятора до операційної системи, можна зібрати лише з трьох «цеглинок»: слідування,
розгалуження й циклу. Це твердження — основа **структурного програмування**, яке визначило вигляд сучасних мов
програмування, зокрема C++. У лекції розглянемо кожну базову структуру в трьох записах — схемою, псевдокодом і
мовою C++, — їхні різновиди, правила комбінування й типові помилки.

## Структурне програмування

У 1960-х програми писали з великою кількістю безумовних переходів `goto`. Такий код важко читати й перевіряти:
щоб зрозуміти, як програма потрапила в певне місце, доводилося відстежувати всі стрибки. Програмісти називали
його «спагеті-кодом».

Два результати змінили підхід:

- **Теорема Бьома–Якопіні** (К. Бьом, Дж. Якопіні, 1966): будь-який алгоритм, заданий схемою з переходами, можна
  перебудувати так, що він використовуватиме лише три структури — слідування, розгалуження й цикл.
- **Стаття Е. Дейкстри «Go To Statement Considered Harmful»** (1968) переконала програмістів, що без `goto`
  програми стають зрозумілішими, а довести їхню правильність — простіше.

Головна властивість базових структур: кожна має **один вхід і один вихід**. Тому будь-яку дію всередині структури
можна замінити іншою структурою — і отримати вкладеність будь-якої глибини, зберігаючи зрозумілість. Так
будуються й структурограми з лекції 8.

## Слідування

Дії виконуються одна за одною в порядку запису. Це найпростіша структура, але саме вона визначає, що
результат однієї дії може використовувати наступна.

```cpp
double a, b;
cin >> a >> b;               // 1. введення
double sum = a + b;          // 2. обчислення
double average = sum / 2;    // 3. обчислення з результатом попередньої дії
cout << average << '\n';     // 4. виведення
```

Помилка в порядку дій — одна з найчастіших: наприклад, обчислення середнього до того, як введено дані.

## Розгалуження

Розгалуження обирає одну з кількох гілок залежно від умови.

### Повне й неповне розгалуження

**Повне** розгалуження має дві гілки:

```text
якщо x ≥ 0 то
    y ← √x
інакше
    вивести «корінь не визначено»
кінець якщо
```

```cpp
if (x >= 0) {
    y = sqrt(x);
} else {
    cout << "корінь не визначено\n";
}
```

**Неповне** розгалуження має лише гілку «так»; якщо умова хибна, нічого не відбувається:

```cpp
if (x < 0) {
    x = -x;    // модуль числа
}
```

### Вкладені розгалуження й ланцюжки умов

Гілка розгалуження може містити інше розгалуження. Коли варіантів кілька, зручно будувати **ланцюжок**
`if … else if … else`. Наприклад, переведення бала з 100-бальної шкали в оцінку:

```cpp
int grade;
if (score >= 90)      grade = 5;
else if (score >= 75) grade = 4;
else if (score >= 60) grade = 3;
else                  grade = 2;
```

Умови перевіряються згори донизу, і спрацьовує перша істинна. Тому порядок умов важливий: якщо поставити
`score >= 60` першою, усі студенти з балом від 60 отримали б трійку.

### Вибір

Якщо гілка визначається значенням цілого виразу, використовують **вибір** — у C++ оператор `switch`:

```cpp
switch (day) {
    case 6:
    case 7:
        cout << "вихідний\n";
        break;
    default:
        cout << "робочий день\n";
}
```

Кожну гілку завершують `break`, інакше виконання «провалиться» в наступну гілку. Іноді це використовують
навмисно (як із днями 6 і 7 вище), але частіше це помилка.

## Цикли

Цикл повторює групу дій — **тіло циклу**. Кожне повторення називають **ітерацією**. Щоб цикл не був
нескінченним, дії в тілі мають наближати виконання умови завершення.

### Цикл з передумовою

Умову перевіряють **перед** кожною ітерацією. Якщо вона хибна від самого початку, тіло не виконається жодного
разу.

Приклад: знайти найменший степінь двійки, не менший за $n$.

```cpp
long long p = 1;
while (p < n) {
    p *= 2;
}
```

Якщо $n \le 1$, тіло не виконається, і $p = 1$ — саме так і має бути.

### Цикл з післяумовою

Умову перевіряють **після** ітерації, тож тіло виконується принаймні один раз. Класичне застосування —
перевірка введення:

```cpp
int month;
do {
    cout << "Введіть номер місяця (1-12): ";
    cin >> month;
} while (month < 1 || month > 12);
```

У C++ цикл `do … while` триває, **поки** умова істинна. У деяких інших мовах (Pascal: `repeat … until`) умова
післяумовного циклу означає навпаки — умову **завершення**. Будьте уважні, перекладаючи алгоритми.

### Цикл з параметром

Коли кількість повторень відома наперед, використовують цикл з параметром (лічильником):

```cpp
double sum = 0;
for (int i = 1; i <= n; i++) {
    sum += 1.0 / i;           // гармонічна сума 1 + 1/2 + ... + 1/n
}
```

Цикл `for` у C++ — це скорочений запис циклу з передумовою: ініціалізація, умова й зміна лічильника зібрані в
одному рядку.

### Цикл «до досягнення точності»

Багато чисельних методів (лекції 16–20) повторюють обчислення, доки результат не стане достатньо точним. Наприклад,
сума ряду $e = \sum_{k=0}^{\infty} \frac{1}{k!}$ з точністю $\varepsilon$:

```cpp
double term = 1.0, e = 0.0;
int k = 0;
while (term >= eps) {
    e += term;
    k++;
    term /= k;                // наступний член: 1/k! = (1/(k-1)!) / k
}
```

Тут кількість ітерацій заздалегідь невідома — вона залежить від $\varepsilon$.

### Вкладені цикли

Тіло циклу може містити інший цикл. Внутрішній цикл виконується повністю на кожній ітерації зовнішнього:

```cpp
for (int i = 1; i <= 9; i++) {
    for (int j = 1; j <= 9; j++) {
        cout << i * j << '\t';
    }
    cout << '\n';
}
```

Ця програма виводить таблицю множення: 9 рядків по 9 чисел, тобто тіло внутрішнього циклу виконується
$9 \cdot 9 = 81$ раз. Кількість повторень вкладених циклів перемножується — це важливо для оцінки швидкості
алгоритмів (лекція 13).

### Дострокове завершення

Оператори `break` (вийти з циклу) і `continue` (перейти до наступної ітерації) не порушують структурності, якщо
використовувати їх обережно: вихід із циклу все одно один — наступна після циклу дія. Приклад — перевірка числа
на простоту:

```cpp
bool isPrime = n >= 2;
for (int d = 2; d * d <= n; d++) {
    if (n % d == 0) {
        isPrime = false;
        break;                // дільник знайдено — далі перевіряти немає сенсу
    }
}
```

## Комбінування структур

Складні алгоритми — це вкладені базові структури. Розглянемо задачу: у масиві з $n$ оцінок порахувати кількість
відмінників (оцінка 5) і знайти середній бал.

```text
кількість ← 0
сума ← 0
для i від 0 до n − 1 виконувати          // цикл
    сума ← сума + оцінка[i]              // слідування в тілі
    якщо оцінка[i] = 5 то                // розгалуження в циклі
        кількість ← кількість + 1
    кінець якщо
кінець для
середній ← сума / n
```

Кожна структура тут має один вхід і один вихід, тому алгоритм легко читати згори донизу й перевіряти частинами.

## Типові помилки

- **Нескінченний цикл.** Умова ніколи не стає хибною: забули змінити лічильник, або змінюють «не ту» змінну.
- **Помилка на одиницю** (off-by-one). `i <= n` замість `i < n` виводить за межі масиву; `i < n` замість
  `i <= n` пропускає останній елемент.
- **Дійсний лічильник.** Цикл `for (double x = 0; x != 1; x += 0.1)` може не зупинитися: через похибки
  округлення $x$ не стане рівно 1 (лекція 15). Використовуйте цілий лічильник або порівняння `<`.
- **Пропущені фігурні дужки.** Без них тіло `if` чи `for` — лише один наступний оператор.
- **`=` замість `==`** в умові: `if (x = 0)` — це присвоювання, а не порівняння.
- **Забутий `break` у `switch`.**

## Підсумки

- За теоремою Бьома–Якопіні будь-який алгоритм можна побудувати зі слідування, розгалуження й циклу.
- Кожна базова структура має один вхід і один вихід, тому структури можна вкладати одну в одну.
- Розгалуження буває повним, неповним, вкладеним і багатоальтернативним (`else if`, `switch`).
- Цикл з передумовою може не виконатися жодного разу, цикл з післяумовою виконується принаймні один раз, цикл з
  параметром — задану кількість разів.
- Кількість повторень вкладених циклів перемножується.
- Найчастіші помилки — нескінченні цикли, помилки на одиницю, дійсні лічильники, `=` замість `==`.
