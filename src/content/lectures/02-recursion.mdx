Матрьошка всередині матрьошки, дзеркало навпроти дзеркала, гілка дерева, схожа на все дерево, — усе це приклади
**рекурсії**: об'єкт або дія визначається через самих себе. У програмуванні рекурсія — один із найпотужніших
прийомів: функція викликає сама себе, розв'язуючи меншу версію тієї самої задачі. У цій лекції розберемо, як
працює рекурсія, як її правильно будувати, де вона доречна, а де шкодить, і розв'яжемо класичні задачі.

## Що таке рекурсія

**Рекурсивне означення** визначає об'єкт через нього самого, але для «меншого» випадку. Класичний приклад —
факторіал:

$$
n! = \begin{cases} 1, & n = 0, \\ n \cdot (n-1)!, & n > 0. \end{cases}
$$

Означення не зациклюється: кожне застосування зменшує $n$, і рано чи пізно доходимо до $0! = 1$.

**Рекурсивна функція** викликає сама себе. Будь-яка правильна рекурсія складається з двох частин:

- **базовий випадок** — задача настільки проста, що відповідь відома без рекурсії ($0! = 1$);
- **рекурсивний крок** — задачу зводять до тієї самої задачі меншого розміру ($n! = n \cdot (n-1)!$).

```cpp
long long factorial(int n) {
    if (n == 0) return 1;              // базовий випадок
    return n * factorial(n - 1);       // рекурсивний крок
}
```

Головне правило: **кожен рекурсивний виклик має наближати до базового випадку.** Інакше рекурсія нескінченна.

## Як виконується рекурсія: стек викликів

Коли функція викликає сама себе, попередній виклик не зникає — він чекає на результат. Для кожного виклику
створюється окремий **кадр стеку** зі своїми параметрами й локальними змінними. Кадри складаються «стопкою»:
останній створений завершується першим.

Обчислення `factorial(4)`:

| Етап | Виклик | Що відбувається |
| --- | --- | --- |
| спуск | `factorial(4)` | чекає на `factorial(3)` |
| спуск | `factorial(3)` | чекає на `factorial(2)` |
| спуск | `factorial(2)` | чекає на `factorial(1)` |
| спуск | `factorial(1)` | чекає на `factorial(0)` |
| базовий випадок | `factorial(0)` | повертає 1 |
| повернення | `factorial(1)` | повертає $1 \cdot 1 = 1$ |
| повернення | `factorial(2)` | повертає $2 \cdot 1 = 2$ |
| повернення | `factorial(3)` | повертає $3 \cdot 2 = 6$ |
| повернення | `factorial(4)` | повертає $4 \cdot 6 = 24$ |

Рекурсія має два етапи: **спуск** (виклики, доки не досягнуто базового випадку) і **повернення** (обчислення
результатів у зворотному порядку). Кількість одночасно відкритих викликів — **глибина рекурсії**; тут вона
дорівнює 5.

Стек має обмежений розмір — зазвичай кілька мегабайтів. Якщо рекурсія надто глибока (десятки чи сотні тисяч
викликів) або нескінченна, програма аварійно завершується з **переповненням стеку** (stack overflow).

## Базові приклади

### Сума цифр числа

Сума цифр числа $n$ дорівнює останній цифрі плюс сума цифр числа без останньої цифри:

```cpp
int digitSum(int n) {
    if (n < 10) return n;                      // одна цифра
    return n % 10 + digitSum(n / 10);
}
```

`digitSum(4096)` = 6 + `digitSum(409)` = 6 + 9 + `digitSum(40)` = 6 + 9 + 0 + 4 = 19.

### Найбільший спільний дільник

Алгоритм Евкліда природно записується рекурсивно: $\gcd(a, b) = \gcd(b, a \bmod b)$, а $\gcd(a, 0) = a$.

```cpp
int gcd(int a, int b) {
    if (b == 0) return a;
    return gcd(b, a % b);
}
```

$\gcd(48, 18) = \gcd(18, 12) = \gcd(12, 6) = \gcd(6, 0) = 6$.

### Швидке піднесення до степеня

Наївно $a^n = a \cdot a^{n-1}$ — це $n$ множень. Але для парного $n$ можна скористатися тим, що
$a^n = \left(a^{n/2}\right)^2$:

$$
a^n = \begin{cases} 1, & n = 0, \\ \left(a^{n/2}\right)^2, & n \text{ парне}, \\ a \cdot a^{n-1}, & n \text{ непарне}. \end{cases}
$$

```cpp
double power(double a, int n) {
    if (n == 0) return 1;
    if (n % 2 == 0) {
        double half = power(a, n / 2);         // обчислюємо один раз!
        return half * half;
    }
    return a * power(a, n - 1);
}
```

Для $n = 1000$ знадобиться лише близько 15 множень замість тисячі: кожні два кроки показник щонайменше
зменшується вдвічі, тож кількість викликів порядку $\log_2 n$.

### Паліндром

Рядок — паліндром, якщо перший і останній символи однакові, а рядок між ними теж паліндром. Порожній рядок і
рядок з одного символу — паліндроми.

```cpp
bool isPalindrome(const string& s, int left, int right) {
    if (left >= right) return true;                    // 0 або 1 символ
    if (s[left] != s[right]) return false;
    return isPalindrome(s, left + 1, right - 1);
}
```

Виклик: `isPalindrome(s, 0, s.size() - 1)`.

### Ханойські вежі

Класична задача: на першому стрижні — $n$ дисків різного розміру (менший на більшому). Потрібно перенести всі
диски на третій стрижень, переносячи за раз один диск і ніколи не кладучи більший диск на менший. Другий стрижень
— допоміжний.

Рекурсивний розв'язок напрочуд короткий. Щоб перенести $n$ дисків з A на C через B:

1. перенести $n - 1$ верхніх дисків з A на B (через C);
2. перенести найбільший диск з A на C;
3. перенести $n - 1$ дисків з B на C (через A).

```cpp
void hanoi(int n, char from, char to, char via) {
    if (n == 0) return;
    hanoi(n - 1, from, via, to);
    cout << from << " -> " << to << '\n';
    hanoi(n - 1, via, to, from);
}
```

Для $n = 3$ програма виводить сім переміщень: A→C, A→B, C→B, A→C, B→A, B→C, A→C. У загальному випадку
переміщень $2^n - 1$: для 64 дисків із легенди — понад $1{,}8 \cdot 10^{19}$. Навіть по одному за секунду це
сотні мільярдів років.

## Коли рекурсія шкодить: числа Фібоначчі

Числа Фібоначчі означені рекурсивно: $F_0 = 0$, $F_1 = 1$, $F_n = F_{n-1} + F_{n-2}$. Пряма реалізація:

```cpp
long long fib(int n) {
    if (n <= 1) return n;
    return fib(n - 1) + fib(n - 2);
}
```

Вона правильна, але катастрофічно повільна. Щоб обчислити `fib(5)`, функція викликає `fib(4)` і `fib(3)`, але
`fib(4)` знову викликає `fib(3)`, і так далі — ті самі значення обчислюються знову й знову. Усього для `fib(5)`
відбувається 15 викликів, для `fib(40)` — понад 331 мільйон. Кількість викликів зростає експоненційно, приблизно
як $1{,}6^n$.

Два способи виправити:

**Мемоізація** — запам'ятовувати вже обчислені значення:

```cpp
long long fibMemo(int n, vector<long long>& memo) {
    if (n <= 1) return n;
    if (memo[n] != -1) return memo[n];                 // уже обчислювали
    return memo[n] = fibMemo(n - 1, memo) + fibMemo(n - 2, memo);
}
// виклик: vector<long long> memo(n + 1, -1); fibMemo(n, memo);
```

**Ітерація** — обчислювати від менших значень до більших:

```cpp
long long fibIter(int n) {
    long long previous = 0, current = 1;
    for (int i = 0; i < n; i++) {
        long long next = previous + current;
        previous = current;
        current = next;
    }
    return previous;
}
```

Обидва варіанти виконують порядку $n$ операцій. Урок: рекурсивне означення не завжди означає, що рекурсивна
реалізація ефективна.

## Рекурсія та ітерація

Будь-яку рекурсію можна замінити циклом — у крайньому разі з явним стеком, у який програма сама складає те, що
при рекурсії зберігалося б у кадрах викликів. І навпаки, будь-який цикл можна записати рекурсивно.

| | Рекурсія | Ітерація |
| --- | --- | --- |
| запис | часто коротший і ближчий до математичного означення | інколи довший |
| пам'ять | кадр стеку на кожен рівень | зазвичай стала |
| швидкодія | накладні витрати на виклики | без викликів |
| ризики | переповнення стеку, повторні обчислення | помилки в керуванні циклом |

Рекурсія природна там, де сама задача має рекурсивну структуру: дерева, вкладені каталоги, вирази з дужками,
«розділяй і володарюй». Для простих лінійних обчислень (сума, факторіал) цикл зазвичай кращий.

Окремий випадок — **хвостова рекурсія**: рекурсивний виклик є останньою дією функції (як у `gcd`). Багато
компіляторів уміють перетворювати її на цикл, і тоді вона не витрачає стек.

## Застосування рекурсії

- **«Розділяй і володарюй».** Задачу ділять на менші незалежні підзадачі, розв'язують їх рекурсивно й поєднують
  результати: бінарний пошук, сортування злиттям і швидке сортування (лекція 12), швидке множення чисел.
- **Обхід дерев.** Каталог файлової системи містить файли й підкаталоги, які містять свої файли й підкаталоги.
  Підрахувати загальний розмір найпростіше рекурсивно: розмір каталогу = розмір файлів + розміри підкаталогів.
- **Перебір варіантів** (пошук з поверненням). Генерація всіх підмножин, перестановок, розв'язання головоломок:
  на кожному рівні рекурсії вибираємо один елемент і рекурсивно перебираємо решту.
- **Розбір виразів.** Вираз з дужками містить підвирази з дужками — компілятори розбирають програми рекурсивно.
- **Фрактали.** Сніжинка Коха, дерево Піфагора, трикутник Серпінського будуються рекурсивним повторенням
  простого правила.
- **Теорія алгоритмів.** Рекурсивні функції — одна з моделей алгоритму (лекція 1).

Приклад перебору: вивести всі підмножини множини $\lbrace 1, 2, \dots, n \rbrace$. Для кожного числа є два
варіанти — взяти його чи ні:

```cpp
void subsets(int k, int n, vector<int>& chosen) {
    if (k > n) {                                   // рішення щодо всіх чисел ухвалено
        for (int x : chosen) cout << x << ' ';
        cout << '\n';
        return;
    }
    subsets(k + 1, n, chosen);                     // не беремо k
    chosen.push_back(k);
    subsets(k + 1, n, chosen);                     // беремо k
    chosen.pop_back();                             // повертаємо стан
}
// виклик: vector<int> chosen; subsets(1, 3, chosen);  — 8 підмножин
```

## Типові помилки

- **Немає базового випадку** або він недосяжний — нескінченна рекурсія й переповнення стеку. Наприклад,
  `factorial(-1)` з функцією вище ніколи не дійде до нуля.
- **Рекурсивний крок не зменшує задачу**: `f(n)` викликає `f(n)` із тим самим аргументом.
- **Повторні обчислення**, як у наївному Фібоначчі.
- **Задовга рекурсія** для великих даних: рекурсивна сума мільйона чисел переповнить стек.
- **Втрачений результат**: виклик `f(n - 1);` без `return` — значення рекурсивного виклику нікуди не передається.

## Підсумки

- Рекурсія — визначення об'єкта чи дії через самих себе для меншого випадку.
- Рекурсивна функція має базовий випадок і рекурсивний крок, що наближає до базового випадку.
- Кожен виклик отримує власний кадр стеку; рекурсія має етапи спуску й повернення; глибина рекурсії обмежена
  розміром стеку.
- Класичні приклади: факторіал, сума цифр, НСД, швидке піднесення до степеня, паліндром, ханойські вежі.
- Наївна рекурсія може повторно обчислювати ті самі значення (Фібоначчі); рятують мемоізація або ітерація.
- Рекурсія природна для «розділяй і володарюй», дерев, перебору, розбору виразів.
