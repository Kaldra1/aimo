## Мета

Навчитися представляти алгоритми псевдокодом і схемами за ГОСТ 19.701-90 (ISO 5807-85), будувати схеми даних,
перекладати схему алгоритму в програму мовою C++ і перевіряти її на тестових даних.

## Обладнання

ПК; редактор діаграм — diagrams.net (draw.io, працює в браузері), Microsoft Visio або LibreOffice Draw;
компілятор C++ (g++, Visual Studio або онлайн-компілятор).

## Основні теоретичні положення

Докладно — у [лекції 9](/lectures/09-flowcharts-espd/). Коротко:

**Схема алгоритму (програми)** показує послідовність дій. Основні символи:

| Символ | Призначення |
| --- | --- |
| термінатор (овал) | «Початок», «Кінець» |
| процес (прямокутник) | обчислення, присвоювання |
| рішення (ромб) | перевірка умови; виходи підписують «так» і «ні» |
| дані (паралелограм) | введення, виведення |
| підготовка (шестикутник) | заголовок циклу з параметром |
| межа циклу (фігури зі зрізаними кутами) | початок і кінець циклу |
| визначений процес | виклик підпрограми |
| з'єднувач (коло) | розрив лінії потоку |
| коментар | пояснення до символу |

**Правила.** Потік іде згори донизу й зліва направо; в інших напрямках на лініях ставлять стрілки. Лінії —
горизонтальні й вертикальні, без зайвих перетинів. Розміри символів однакові: висота $a$, ширина $b = 1{,}5a$.
У символах — короткий текст, а не код мови програмування.

**Схема даних** показує, звідки надходять дані, як обробляються й куди записуються результати: носії даних
(клавіатура — «ручне введення», файл — «запам'ятовувані дані», екран — «дисплей», друкований документ —
«документ») з'єднують лініями із символами процесів обробки.

**Порядок роботи над алгоритмом:** постановка задачі → вибір тестів → псевдокод → схема → програма → перевірка на
тестах. Схему, побудовану після псевдокоду, простіше тримати структурною: без переходів «навскоси» й
перетинів ліній.

## Хід роботи

1. Отримайте номер варіанта. Запишіть постановку задачі: вхідні дані (тип, обмеження), вихідні дані, формули.
2. Складіть 3–4 тести **до** написання програми: звичайний випадок, крайові випадки (порожній масив, нуль,
   від'ємні значення), випадок некоректних даних, якщо він можливий. Для кожного тесту запишіть очікуваний
   результат.
3. Запишіть алгоритм псевдокодом (домовленості — у лекції 8).
4. Побудуйте в редакторі діаграм **схему алгоритму** за ГОСТ 19.701-90. Використайте щонайменше один цикл і
   одне розгалуження. Якщо в алгоритмі є підпрограма, зобразіть її виклик символом «визначений процес» і
   побудуйте для неї окрему схему.
5. Побудуйте **схему даних**: джерела вхідних даних, процес обробки й носії результатів.
6. Напишіть програму мовою C++, дотримуючись структури схеми (кожен символ — відповідна конструкція).
7. Перевірте програму на тестах із кроку 2. Якщо результат не збігається з очікуваним, знайдіть помилку й
   виправте і програму, і схему.
8. Оформіть звіт.

## Варіанти

| Варіант | Завдання |
| --- | --- |
| 1 | Протабулювати функцію $y = x^2$ для $x < 0$ і $y = \sqrt{x}$ для $x \ge 0$ на відрізку $[-2; 2]$ з кроком $0{,}5$. |
| 2 | Обчислити суму ряду $\sum_{k=0}^{\infty} \frac{(-1)^k x^k}{k!}$ з точністю $\varepsilon$ і порівняти з $e^{-x}$. |
| 3 | Знайти найбільший елемент масиву й номер його першого входження. |
| 4 | Порахувати кількість додатних, від'ємних і нульових елементів масиву. |
| 5 | Знайти середнє арифметичне елементів масиву й кількість елементів, більших за середнє. |
| 6 | Перевірити, чи є натуральне число простим. |
| 7 | Знайти найбільший спільний дільник (алгоритм Евкліда) і найменше спільне кратне двох чисел. |
| 8 | Перевірити, чи є рядок паліндромом (без бібліотечних функцій обертання). |
| 9 | Порахувати кількість слів у рядку (слова розділені одним або кількома пробілами). |
| 10 | Розв'язати рівняння $ax^2 + bx + c = 0$ з урахуванням випадків $a = 0$, $D < 0$, $D = 0$, $D > 0$. |
| 11 | Знайти суму цифр натурального числа й кількість парних цифр. |
| 12 | Вивести всі позиції, на яких у масиві трапляється задане значення, або повідомлення, що його немає. |
| 13 | Обчислити $n$-те число Фібоначчі ітеративно ($F_1 = F_2 = 1$). |
| 14 | Прочитати з текстового файлу прізвища й оцінки студентів, обчислити середній бал групи й записати у файл список студентів з оцінкою, вищою за середню. |
| 15 | Перевести натуральне число з десяткової системи в двійкову. |

Для варіанта 14 схема даних обов'язково містить вхідний і вихідний файли. Для інших варіантів на схемі даних
покажіть введення з клавіатури й виведення на екран.

## Зміст звіту

1. Тема, мета роботи, номер варіанта й постановка задачі.
2. Тести з очікуваними результатами.
3. Алгоритм псевдокодом.
4. Схема алгоритму за ГОСТ 19.701-90 (і схеми підпрограм, якщо є).
5. Схема даних.
6. Текст програми C++ і результати її виконання на тестах.
7. Висновки: які правила оформлення схем застосовано, які помилки виявлено під час перевірки.

## Контрольні запитання

1. Що таке ЄСПД? Який стандарт встановлює правила виконання схем?
2. Які види схем визначає ГОСТ 19.701-90? Чим схема даних відрізняється від схеми алгоритму?
3. Назвіть основні символи схем алгоритмів і їхнє призначення.
4. Як на схемі зобразити цикл із параметром? А цикл з передумовою?
5. Коли на лініях потоку обов'язково ставлять стрілки?
6. Скільки входів і виходів може мати символ «рішення»? Як підписують виходи?
7. Навіщо потрібен символ «з'єднувач»?
8. Чому перед побудовою схеми зручно записати алгоритм псевдокодом?
9. Як перевірити, що програма відповідає схемі?
10. Які тести варто скласти для вашого варіанта і чому саме такі?
