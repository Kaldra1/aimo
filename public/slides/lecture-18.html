Три способи наближення

Дано n пар (xᵢ, yᵢ), шукаємо ŷ = f(x)

Інтерполяція

f(xᵢ) = yᵢ

Точний збіг у вузлах. Доречна, коли табличні значення точні

Апроксимація

f(xᵢ) ≈ yᵢ

Допускає відхилення заради відповідності всій сукупності. Природна для вимірювань із шумом

Екстраполяція

x ∉ [x_min; x_max]

Lₙ₋₁(x) = Σ yᵢ ℓᵢ(x) ℓᵢ(x) = Π_{j≠i} (x − xⱼ) / (xᵢ − xⱼ) ℓᵢ = 1 у своєму вузлі, 0 — в інших
Точки (1, 2), (2, 3), (3, 6)

− 3(x−1)(x−3)
+ 3(x−1)(x−2)
= x² − 2x + 3
Перевірка: 2, 3, 6 у вузлах; L₂(1.5) = 2.25 
double lagrange3(double t, const array<double,3>& x,
                 const array<double,3>& y) {
    double result = 0.0;
    for (int i = 0; i < 3; ++i) {
        double term = y[i];
        for (int j = 0; j < 3; ++j)
            if (j != i) term *= (t - x[j]) / (x[i] - x[j]);
        result += term;
    }
    return result;
}

Нормальні рівняння для ŷ = a + bx

∂S/∂a = 0, ∂S/∂b = 0
na + bΣxᵢ = Σyᵢ
aΣxᵢ + bΣxᵢ² = Σxᵢyᵢ
D = nΣxᵢ² − (Σxᵢ)² b = (nΣxᵢyᵢ − ΣxᵢΣyᵢ) / D a = (Σyᵢ − bΣxᵢ) / n

fitLine у C++17

Line fitLine(const vector<double>& x, const vector<double>& y) {
    if (x.size() != y.size() || x.size() < 2)
        throw runtime_error("Invalid data size");
    double meanX = 0, meanY = 0;
    for (size_t i = 0; i < x.size(); ++i) {
        if (!isfinite(x[i]) || !isfinite(y[i])) throw …;
        meanX += x[i];  meanY += y[i];
    }
    meanX /= x.size();  meanY /= y.size();
    double sxx = 0, sxy = 0;
    for (size_t i = 0; i < x.size(); ++i) {
        double dx = x[i] - meanX;
        sxx += dx * dx;  sxy += dx * (y[i] - meanY);
    }
    if (!(sxx > 0.0)) throw runtime_error("Degenerate data");
    double b = sxy / sxx;
    return {meanY - b * meanX, b};
}
