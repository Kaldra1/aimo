Приклад: ∫₀¹ x² dx = 1/3, n = 2, h = 0.5
double rectangles(double (*f)(double),
                  double a, double b,
                  int n, double shift) {
    const double h = (b - a) / n;
    double sum = 0.0;
    for (int i = 0; i < n; ++i)
        sum += f(a + (i + shift) * h);
    return h * sum;
}  // 0 — ліві, 1 — праві, 0.5 — середні

double simpson(double a, double b, int n) {
    if (n <= 0 || n % 2 != 0 || !(a < b))
        throw invalid_argument("…");
    const double h = (b - a) / n;
    double sum = f(a) + f(b);
    for (int i = 1; i < n; ++i)
        sum += (i % 2 == 0 ? 2.0 : 4.0) * f(a + i * h);
    return h * sum / 3.0;
}

    double coarse = trapezoid(a, b, n);

Що забрати з лекції

01Однобічні різниці — O(h), центральна — O(h²); друга різниця чутлива до шуму
02Крок — баланс похибки методу й округлення; найменший не найкращий
03Ліві й праві прямокутники — перший порядок, середні й трапеції — другий
04Сімпсон — парне n, четвертий порядок за достатньої гладкості
05Рунге оцінює похибку на дрібнішій сітці, якщо виконується асимптотична модель
06Вдалий приклад не змінює загального порядку методу
