Лекція 11 · Постановка задачі01

Що означає «відсортувати»

Дано масив a₀, a₁, …, aₙ₋₁. Переставити елементи так, щоб

a₀ ≤ a₁ ≤ … ≤ aₙ₋₁

Це сортування за неспаданням. За незростанням — інший знак порівняння.

Ключ

Сортують не лише числа, а й записи. Поле, за яким порівнюють, — ключ: наприклад, середній бал студента.

Лекція 11 · Постановка задачі02

Як порівнювати методи

01

Порівняння й переміщення

Кількість порівнянь ключів і переміщень елементів (обмінів або зсувів) — основні міри трудомісткості

02

Сортування на місці

Без додаткового масиву: додаткова пам'ять O(1)

03

Стійкість

Елементи з однаковими ключами зберігають взаємний порядок. Спершу за прізвищем, потім стійко за групою — у групі прізвища лишаться за абеткою

04

Поведінка на різних даних

Найкращий, середній і найгірший випадки: відсортований, випадковий, зворотний масив

Лекція 11 · Бульбашка06

Бульбашка: реалізація й аналіз

C++
void bubbleSort(vector<int>& a) {
    int n = a.size();
    for (int pass = 0; pass < n - 1; pass++) {
        bool swapped = false;
        for (int j = 0; j < n - 1 - pass; j++) {
            if (a[j] > a[j + 1]) {
                swap(a[j], a[j + 1]);
                swapped = true;
            }
        }
        if (!swapped) break;
    }
}

Найгірший випадок

Зворотний порядок: n(n−1)/2 порівнянь і стільки ж обмінів

Найкращий випадок

Масив упорядкований: завдяки прапорцю один прохід, n − 1 порівнянь

Інверсії

Пари i < j, де aᵢ > aⱼ. Обмінів рівно стільки, скільки інверсій — у нас 7

Стійкий

Рівні сусіди не міняються: умова >, а не >=

Вибір: реалізація й аналіз

C++
void selectionSort(vector<int>& a) {
    int n = a.size();
    for (int i = 0; i < n - 1; i++) {
        int minIndex = i;
        for (int j = i + 1; j < n; j++) {
            if (a[j] < a[minIndex]) minIndex = j;
        }
        if (minIndex != i) swap(a[i], a[minIndex]);
    }
}

Лекція 11 · Вставки10

Вставки: реалізація й аналіз

C++
void insertionSort(vector<int>& a) {
    int n = a.size();
    for (int i = 1; i < n; i++) {
        int key = a[i];
        int j = i - 1;
        while (j >= 0 && a[j] > key) {
            a[j + 1] = a[j];   // зсув праворуч
            j--;
        }
        a[j + 1] = key;        // вставка
    }
}
Порядок умов

Спершу j >= 0, потім a[j]. Завдяки скороченому && при j = −1 друга умова не перевіряється — виходу за межі немає.

Найгірший випадок

Зворотний порядок: n(n−1)/2 порівнянь і зсувів

Найкращий випадок

Відсортований масив: n − 1 порівнянь, жодного зсуву

Майже відсортовані дані

Дуже швидко: зсувів стільки, скільки інверсій

Стійкий, на місці

Для малих масивів і як частина ефективних методів (лекція 12)

Квадратична трудомісткість

Масив більший удесятеро — час роботи більший приблизно у сто разів

≈ 5·10⁵

≈ 5·10¹¹
порівнянь — хвилини чи години

bool testSort(void (*sortFunction)(vector<int>&)) {
    mt19937 rng(42);
    for (int test = 0; test < 1000; test++) {
        vector<int> a(rng() % 50);
        for (int& x : a) x = int(rng() % 21) - 10;

        if (a != expected) return false;

Лекція 11 · Підсумки14

Що забрати з лекції

01Сортування впорядковує за ключем; важливі порівняння, переміщення, стійкість і пам'ять
02Бульбашка міняє сусідів; прапорець зупиняє, щойно масив відсортовано
03Вибір: порівнянь завжди n(n−1)/2, обмінів не більше n − 1; нестійкий
04Вставки — найшвидший з простих методів на майже впорядкованих даних
05Обміни бульбашки й зсуви вставок дорівнюють кількості інверсій
06Усі три методи квадратичні — лише для невеликих масивів
