Лекція 10 · Структурне програмування02

Від «спагеті-коду» до трьох структур

У 1960-х програми писали з безліччю переходів goto. Такий код важко читати й перевіряти: доводилося відстежувати всі стрибки.

1966

Теорема Бьома–Якопіні

К. Бьом і Дж. Якопіні: будь-який алгоритм, заданий схемою з переходами, можна перебудувати так, щоб він використовував лише слідування, розгалуження й цикл.

1968

«Go To Statement Considered Harmful»

Стаття Е. Дейкстри переконала програмістів: без goto програми зрозуміліші, а довести їхню правильність простіше.

Ці ідеї — основа структурного програмування, яке визначило вигляд сучасних мов, зокрема C++.

Лекція 10 · Слідування04

Слідування: порядок має значення

Дії виконуються одна за одною в порядку запису. Результат однієї дії може використовувати наступна.

C++ · середнє двох чисел
double a, b;
cin >> a >> b;               // 1. введення
double sum = a + b;          // 2. обчислення
double average = sum / 2;    // 3. використовує 2
cout << average << '\n';     // 4. виведення

Ланцюжок залежностей

average залежить від sum, а sum — від введених a і b

Лекція 10 · Розгалуження08

Вибір: оператор switch

Гілка визначається значенням цілого виразу, а не логічною умовою

C++ · день тижня
switch (day) {
    case 6:
    case 7:
        cout << "вихідний\n";
        break;
    default:
        cout << "робочий день\n";
}

break завершує гілку

Без нього виконання «провалиться» в наступну гілку

Навмисне провалювання

case 6 порожній і падає в case 7: обидва дні — вихідні

Але частіше — помилка

Забутий break — у списку типових помилок

Цикли

Цикл повторює тіло; кожне повторення — ітерація. Щоб цикл не був нескінченним, тіло має наближати умову завершення.

≥ 0 разівЗ передумовою
≥ 1 разЗ післяумовою
n разівЗ параметром
Лекція 10 · Цикли10

Передумова чи післяумова

while — умова до тіла

≥ 0 разів

Найменший степінь двійки, не менший за n

long long p = 1;
while (p < n) {
    p *= 2;
}

Якщо n ≤ 1, тіло не виконається жодного разу, і p = 1 — саме так і має бути.

do … while — умова після

≥ 1 раз

Класичне застосування — перевірка введення

int month;
do {
    cout << "Номер місяця (1-12): ";
    cin >> month;
} while (month < 1 || month > 12);

Запитати треба хоча б раз — тому умову перевіряємо після введення.

Увага C++ do … while триває, поки умова істинна. Pascal repeat … until — навпаки: умова завершення.

Лекція 10 · Цикли12

Цикл «до досягнення точності»

Сума ряду e = Σ 1/k!, k = 0 … ∞, з точністю ε

C++
double term = 1.0, e = 0.0;
int k = 0;
while (term >= eps) {
    e += term;
    k++;
    term /= k;   // 1/k! = 1/(k−1)! / k
}

Кількість ітерацій заздалегідь невідома — вона залежить від ε. Новий член рахуємо з попереднього, без факторіала.

Лекція 10 · Помилки16

Типові помилки

01

Нескінченний цикл

Умова ніколи не стає хибною: забули змінити лічильник або змінюють «не ту» змінну

02

Помилка на одиницю

i <= n замість i < n — вихід за межі масиву; навпаки — пропущений останній елемент

03

Дійсний лічильник

for (double x = 0; x != 1; x += 0.1) може не зупинитися. Цілий лічильник або <

04

Пропущені фігурні дужки

Без них тіло if чи for — лише один наступний оператор

05

= замість ==

if (x = 0) — це присвоювання, а не порівняння

06

Забутий break у switch

Виконання «провалюється» в наступну гілку

НСД і НСК

Оформити алгоритм Евкліда окремою процедурою НСД(a, b) зі своєю блок-схемою. Основний алгоритм обчислює НСК = a · b / НСД(a, b), виклик процедури позначити блоком «визначений процес».

Побудувати дві блок-схеми й виконати трасування для a = 48, b = 18.
