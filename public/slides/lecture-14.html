Лекція 14 · Бінарний пошук03

Бінарний пошук

1Порівняти x із середнім елементом
2Менший — шукати ліворуч, більший — праворуч
3Область щоразу зменшується вдвічі
ПорівняньO(log n)
C++
int binarySearch(const vector<int>& a, int x) {
    int low = 0, high = (int)a.size() - 1;
    while (low <= high) {
        int mid = low + (high - low) / 2;
        if (a[mid] == x) return mid;
        if (a[mid] < x) low = mid + 1;
        else high = mid - 1;
    }
    return -1;   // не знайдено
}

    string surname;
    double average;

sort(group.begin(), group.end(),
     [](const Student& x, const Student& y) {

    return x.surname < y.surname;      // прізвище

Лекція 14 · Компаратори11

Компаратор має бути строгим

Поводиться як <

Для однакових елементів — false. Тому <, а не <=

Узгоджений

Якщо x раніше за y, а y — за z, то x раніше за z

Небезпечно

З <= std::sort може працювати неправильно й вийти за межі масиву

Альтернатива · стійкість
1sort за прізвищем 2stable_sort за балом

У межах однакового бала прізвища лишаються за абеткою
