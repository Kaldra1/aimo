Лекція 1 · Поняття02

Інтуїтивне поняття алгоритму

Алгоритм — скінченний набір точних інструкцій, що визначає послідовність дій для розв'язання задач певного класу: для будь-яких допустимих вхідних даних результат за скінченну кількість кроків

Виконавець

Людина, робот, комп'ютер, абстрактна машина. Уміє обмежений набір дій — систему команд

Лише зрозумілі команди

«Знайди корінь» — не алгоритм для калькулятора; послідовність натискань клавіш — алгоритм

1

2

3
a ← b, b ← r, повернутися до кроку 1

Лекція 1 · Моделі07

Теза Черча–Тюрінга

Будь-яка функція, яку можна обчислити інтуїтивно зрозумілим алгоритмом, обчислюється машиною Тюрінга

Моделі рівносильні

Доведено строго: що обчислюється в одній — обчислюється в будь-якій

Не теорема

«Інтуїтивний алгоритм» не має точного означення — довести неможливо. Контрприкладу за століття немає

Для програміста

Усі мови однаково «потужні» за тим, що можна обчислити — різняться зручністю й швидкодією

Лекція 1 · Базові поняття08

Алфавіт, слово, обчислювана функція

Слово — скінченна послідовність символів; λ — порожнє слово довжини 0

Будь-які дані кодуються словом: число — рядком цифр, таблиця — рядком із роздільниками, програма — її текстом

Область застосовності

Вхідні дані, для яких алгоритм зупиняється й дає результат

Обчислювана функція

Є алгоритм, що обчислює її значення для кожного аргументу з області визначення

Часткова функція

Не визначена для деяких аргументів — там алгоритм працює нескінченно
