Лекція 20 · Постановка01

Унімодальність і правила відкидання

Припущення

Неперервна, єдиний мінімум, строго спадає до нього й строго зростає після. Мінімум може бути на межі

f(x₁) < f(x₂)→ [a, x₂]
f(x₁) > f(x₂)→ [x₁, b]
рівніу коді — до першої гілки
Чому працює перше правило

Якби мінімум лежав правіше x₂, обидві точки були б на спадній частині: f(x₁) > f(x₂). Суперечність

Зупинка · ε — похибка координати
b − a ≤ 2ε
x̂ = (a + b)/2, |x̂ − x*| ≤ ε

Близькість значень функції не замінює цього критерію: на пологій ділянці значення майже рівні далеко від мінімуму

1Довжина ≤ 2ε — повернути середину
2Обчислити x₁, x₂ і обидва значення f

4Повернутися до перевірки

Lₖ₊₁ = (Lₖ + δ)/2

k_д = ⌈log₂ ((L₀ − δ)/(2ε − δ))⌉
Викликів функції: 2k_д. Дуже мале δ — точки збігаються через округлення

goldenSection у C++17

const double tau = (sqrt(5.0) - 1.0) / 2.0;
double x1 = a + (1 - tau) * (b - a), x2 = a + tau * (b - a);
double y1 = evaluate(x1, calls), y2 = evaluate(x2, calls);
while (b - a > 2 * eps) {
    if (iterations >= 1000) throw …;
    if (y1 <= y2) {
        b = x2;  x2 = x1;  y2 = y1;
        ++iterations;
        if (b - a <= 2 * eps) break;
        x1 = a + (1 - tau) * (b - a);
        if (!(a < x1 && x1 < x2 && x2 < b)) throw …;
        y1 = evaluate(x1, calls);
    } else {
        a = x1;  x1 = x2;  y1 = y2;
        ++iterations;
        if (b - a <= 2 * eps) break;
        x2 = a + tau * (b - a);
        if (!(a < x1 && x1 < x2 && x2 < b)) throw …;
        y2 = evaluate(x2, calls);
    }
}
return {a + (b - a) / 2, a, b, iterations, calls};
