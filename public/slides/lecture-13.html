Оцінки зверху, знизу й точна

Oзверху
T(n) ≤ c · g(n)

Росте не швидше за g(n)

Ωзнизу
T(n) ≥ c · g(n)

Росте не повільніше за g(n)

Θточна
O(g) і Ω(g) водночас

Росте так само, як g(n)

Для O і Ω: існують c > 0 і n₀, такі що нерівність виконується для всіх n ≥ n₀
Приклад O · c = 15, n₀ = 13n² + 5n + 7 ≤ 15n² ⇒ O(n²)
Приклад Θ · вибірn(n − 1) / 2 = Θ(n²)

Дерево рішень

Чи можна сортувати порівняннями швидше за n log n? Ні — і це можна довести

Три елементи a₁, a₂, a₃

Вузол

Порівняння двох елементів; дві гілки — дві відповіді

Листок

Перестановка, яку алгоритм видає як відповідь. Потрібні всі n!

Лекція 13 · Нижня оцінка13

Межа Ω(n log n) для порівнянь

1≥ n! листківкожна перестановка — можлива відповідь
2≤ 2ʰ листківу двійковому дереві висоти h
3h ≥ log₂n!з нерівності 2ʰ ≥ n!
4h = Ω(n log n)Стірлінг: log₂n! ≈ n log₂n − 1,44n
Приклад · n = 8
8! = 40 320
log₂ 40 320 ≈ 15,3

Лекція 13 · Експеримент16

Експериментальна перевірка

C++ · <chrono>
template <typename Sort>
double measureMs(Sort sortFunction, const vector<int>& data) {
    vector<int> a = data;            // сортуємо копію
    auto start = chrono::steady_clock::now();
    sortFunction(a);
    auto finish = chrono::steady_clock::now();
    return chrono::duration<double, milli>(finish - start).count();
}

int main() {
    mt19937 rng(2024);
    for (int n : {1000, 2000, 4000, 8000, 16000}) {

            sort(a.begin(), a.end()); }, data);

    }
}

Лекція 13 · Підсумки17

Що забрати з лекції

01Складність — кількість операцій (часова) або додаткова пам'ять (просторова) як функція від n
02Найкращий, середній, найгірший випадки; найгірший дає гарантію
03O — зверху, Ω — знизу, Θ — точна; сталі й молодші доданки відкидають
04Вкладені цикли перемножують, ділення навпіл дає log n, рекурсію — через рекурентні співвідношення
05Сортування порівняннями — Ω(n log n) у найгіршому випадку; злиття й пірамідальне оптимальні
06Теорію перевіряють експериментом: подвоєння n учетверо збільшує час квадратичного алгоритму
